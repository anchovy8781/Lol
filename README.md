# 스타트업 생존기

한국 스타트업 창업·성장 경영 시뮬레이션. `index.html` 하나로 동작하며, 브라우저에서 바로 열면 됩니다.

## 특징
- **업종 5종**: B2B SaaS, B2C 구독 앱, D2C 커머스, 버티컬 마켓플레이스, 제조업(B2B 부품). 업종마다 매출 구조와 비용 구조가 다릅니다 (앱마켓 수수료, 원가·택배비·PG수수료, 공급자 유동성 등).
- **제조업**: 공장 임차·매입, 생산라인 착공(CAPEX, 감가상각), 생산직 인력, 위탁생산(OEM), 수율, 재고와 생산 계획, 원자재 가격, 납기 충족률, 60일 매출채권(흑자도산 위험), IATF 16949·CE 인증, 스마트공장 지원사업, 중진공 시설자금, 산업재해와 중대재해처벌법.
- **난이도 3단계**: 입문 / 현실 / 하드코어. 자본, 고객 유입, 이탈, 투자 매력도, 지원사업 선정률, 상장 심사, 위기 이벤트 빈도가 달라집니다.
- **멘토의 조언**: 지금 상황에서 가장 급한 일 3가지를 알려주고 해당 탭으로 이동시켜 줍니다.
- **무한 모드**: 시간 제한 없이 상장 이후에도 계속 경영. 10년 챌린지 모드도 선택 가능.
- **상장과 주식시장**: 일반 상장과 기술특례 상장 트랙, 주관사·지정감사 → 기술성 평가 → 예비심사 → 수요예측·공모. 상장 후 월간 주가, 분기 실적과 컨센서스(어닝 서프라이즈/쇼크), 보호예수와 VC 오버행, 블록딜, 유상증자, 자사주, 배당, 관리종목·상장폐지, 코스피 이전상장, 행동주의 펀드.
- **해외 진출**: 동남아·일본·중국·유럽·미국. 진출비, 현지 법인 운영비, 안착 기간.
- **경쟁사**: 함께 성장하는 라이벌 회사, 점유율 경쟁, 할인 공세, 경쟁사 인수.
- **이사회 목표**: 분기마다 주어지는 목표와 이사회 신뢰도, 대표 교체 위기.
- **마케팅 채널 5종**: 검색광고, SNS, 유튜브·인플루언서, 콘텐츠·SEO(누적 효과), 전시회·오프라인. 업종별 채널 적합도, 채널별 한계 CAC, 계절성.
- **제품 로드맵**: 업종별 6개 기능을 개발력 배분으로 출시 (전환율·이탈·객단가·시장규모·원가·수율 효과).
- **분석**: 코호트 리텐션 표, 유닛 이코노믹스, 채널별 성과.
- **제도**: 벤처기업 확인, 기업부설연구소(연구인력개발비 세액공제 25%, 10년 이월), 전문연구요원(병역특례) 채용, ISMS-P 의무 인증과 과태료, 육아휴직과 대체인력 지원금, 4대보험 항목별 요율.
- **거시경제**: 기준금리(대출 금리·투자심리 연동), 원/달러 환율(해외 매출·원자재 연동).
- **현금 흐름**: SaaS·앱 연간 선결제(선수수익), 제조업 매출채권.
- **조직**: 1인당 처리 가능 매출 한계(조직 과부하), 대량 채용, 직원 성향(성장형·리더십·독불장군·꾸준함·이직러), 역량 성장과 승진 요청, 퇴사 면담 사유, 자체 사옥.
- **대표 개인 재무**: 대표 급여와 생활비, 개인 자산.
- **실시간 라이브**: 분기 실적 발표(카운트다운 → 매출·영업이익 공개 → 시간외 주가, 상·하한가), 상장 첫날(타종 → 시초가 → 장중 흐름, 따블·따따블), 신기능 출시(실시간 리뷰). 서프라이즈 크기에 따라 반응 채팅이 폭발합니다.
- **종목토론방**: 주가·실적·공시(블록딜, 유증, 배당, 테마)에 반응하는 게시글과 댓글, 대표 공식 입장문(약속은 다음 실적에서 심판받음).
- **커뮤니티와 언론**: 익명 직장인 리뷰(평점이 채용에 영향), 언론 보도 피드.
- **추가 이벤트**: IR 파트너 미팅 질의응답(데이터 부풀리기는 실사에서 위험), 테마주 편입과 거품 붕괴, 정기 주주총회, 경제 예능 출연과 공언 검증, 고객 응대 밈.
- **대표의 삶**: 여행, 스포츠카, 아파트, 기부, 엔젤 투자, 건강관리.
- **출시 전 대기자 명단과 정식 출시 라이브**, **마일스톤 축하 연출**, **그로스 실험실(A/B 테스트)**, **팀 이벤트**(워크숍·해커톤·회식·포상), **국내 스타트업 기업가치 순위**, **연말 시상식·창업 경진대회·고객의 목소리** 이벤트.
- **보상·복지 정책**: 정기 성과급(분기/반기/연 1회, 연봉 비율 고정형 또는 영업이익 공유형), 자동 레크리에이션(월례 회식, 분기 워크숍, 반기 해외 워크숍, 동호회).
- **대표 레벨**: 경험치로 레벨업하며 개발·영업·인맥·회복력을 성장시키고 칭호를 얻습니다.
- **라이브 커머스 방송**, **시즌 빅세일**, **스카우트 전쟁**, **직원 경조사** 이벤트.
- **업무 위임**: 직원 10·30·80·200명마다, 그리고 리드급 PM·경영지원이나 공동창업자가 있으면 대표 시간표가 1칸씩 늘어납니다 (최대 13칸, 칸당 체력 소모는 줄어듦).
- **AI 자동 플레이**: AI 대표가 시간표·마케팅·채용·투자·지원사업·인증·이벤트 선택을 대신합니다. 안정형/균형형/공격형, 속도 4단계, 위기·인수 제안·상장 순간에는 멈추고 직접 결정하는 옵션, 이번 달만 AI 추천 받기.
- **업적 33종**, **자동 진행**(3개월·1년, 결정할 일이 생기면 정지), **연쇄창업**(엑싯 자금과 경험을 이월해 새 회사 창업).
- **월 단위 경영**: 대표의 한 달을 8칸으로 나눠 개발·고객 인터뷰·영업·IR·채용·팀 관리·행정·휴식에 배분합니다. 체력이 바닥나면 응급실에 가고, 세 번이면 번아웃 엔딩입니다.
- **제품과 PMF**: 완성도, 기술부채, 숨겨진 PMF 잠재력. 숀 엘리스 40% 테스트로 신호를 확인하고, 필요하면 피벗합니다.
- **성장 모델**: 자연 유입·바이럴, 유료 광고(체감 한계 CAC), 영업. 시장 포화(TAM), 이탈률, LTV/CAC, CAC 회수기간.
- **팀**: 직군·레벨별 시장 연봉, 오퍼 수락 확률, 온보딩, 사기, 이직, 권고사직(해고예고수당), 퇴직금, 스톡옵션, 3월 연봉 협상, 브룩스의 법칙.
- **재무·세무**: 4대보험 사업주분 10.5%, 퇴직급여 충당 8.33%, 분기 부가세(1·4·7·10월), 3월 법인세(9/19/21% + 지방세, 이월결손금, 창업중소기업 감면), 임차보증금.
- **투자**: 엔젤부터 Pre-IPO까지. 투자 매력도, IR 진행, 복수 텀시트, 실사와 부결, RCPS, ESOP 설정, 지분 희석, 청산우선권 반영 매각 정산, 브릿지 CB.
- **정부지원**: 초기창업패키지(2~3월 공고), TIPS(운영사 투자 필요), 기술보증기금 보증대출, 창업지원센터 입주.
- **이벤트 20여 종**: 서버 장애, 인재 유출, 대기업 진출, 개인정보 유출 과징금, 대기업 PoC, 공동창업자 갈등(베스팅 유무에 따라 다른 결과), 노동청 진정, 바이럴, 세무조사, 특허 경고장, M&A 제안 등.
- **엔딩**: 매각, 애크하이어, 폐업, 상장폐지 (10년 챌린지는 번아웃과 10년 결산 추가). 진행 상황은 브라우저에 자동 저장됩니다.
